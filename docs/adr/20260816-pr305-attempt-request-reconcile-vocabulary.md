# 시도·호출·대사를 세 어휘로 가르고 컬럼 이름을 그 어휘에 맞춘다

- Status: accepted
- Date: 2026-08-16

## Context

결과를 모르는 동안 같은 키로 다시 부르기로 하면서 **`attempt_count`가 부른 횟수를 세지 않게 됐다.** 그때부터 문서마다 같은 변명이 붙었다.

```
"부른 횟수가 아니다"                      여덟 곳
"한 커밋에 들되 오르는 조건이 다르다"       네 곳
```

**변명이 필요하다는 것 자체가 이름이 틀렸다는 신호다.** 원인이 둘이었다.

**하나 — `count`인데 세지 않는다.** 그 값이 하는 일은 멱등키에 붙일 **번호**를 만드는 것이지 무언가를 세는 것이 아니다. 같은 키로 열 번 불러도 그대로다.

**둘 — `attempt_count`와 `last_attempt_at`이 이름은 짝인데 갱신 조건이 다르다.** 앞은 새로운 시도에만, 뒤는 부를 때마다 갱신된다. 이름이 짝이라 읽는 쪽이 함께 움직인다고 읽는다.

뿌리를 따라가니 **용어집 안에서 "시도"가 두 뜻으로 쓰이고 있었다.** "환불 시도"는 결제사를 한 번 요청하는 일이고 "환불 시도 횟수"는 새로운 시도를 몇 번 만들었는지였다. 같은 키로 열 번 부르면 앞 정의로는 열 시도, 뒤 정의로는 한 시도다. **세는 단위가 정의되지 않았다.**

## Decision

**어휘를 셋으로 가른다.**

```
호출 (request)     결제사를 부른 한 번.  같은 키로 열 번 부르면 열 번
시도 (attempt)     멱등키 하나에 대응.   여러 호출이 한 시도에 속할 수 있다
대사 (reconcile)   대사가 집은 것
```

**이름을 그 어휘에 맞춘다.**

```
attempt_count    →  attempt_seq          시도 번호.  세는 값이 아니라 몇 번째인가
last_attempt_at  →  last_requested_at    마지막으로 부른 시각.  호출 어휘다
reconcile_count      그대로               대사가 집은 횟수.  진짜 카운터다
```

**`requested_count`를 만들지 않는다.** 읽는 곳이 없다 — 재요청 상한은 없앴고, 백오프는 `reconcile_count`가, 키 생성은 `attempt_seq`가, 대사 유예는 `last_requested_at`이 맡는다. 조사에는 호출 기록을 세면 되고, 거래 테이블에 사본을 두면 둘이 어긋날 자리만 생긴다.

**접두어를 `requested_`로 통일하지 않는다.** `requested_seq`로 하면 호출 어휘인데 호출마다 오르지 않아 **방금 없앤 문제가 그대로 돌아온다.**

**용어집에 "결제사 호출"을 세운다.** 시도와 호출을 가르는 정의가 없어서 생긴 일이므로 그 둘을 가르는 자리를 만든다.

## Consequences

- **이름이 틀리지는 않게 됐지만 해명은 남긴다.** `attempt_count`일 때는 이름 자체가 거짓이었고 지금은 아니다. 다만 **"시도"가 일상적으로 "부른 횟수"로 읽히는 것까지 이름이 막지는 못한다.** 그 해명이 없으면 부를 때마다 올리는 구현이 나오고, 결과를 모르는 건에 새 키가 나가 **같은 돈이 두 번 움직인다.** "한 커밋에 들되 오르는 조건이 다르다"도 이름으로는 안 드러나므로 함께 남긴다.
- **`attempt_seq`와 `last_requested_at`이 짝이 아님이 이름에서 드러난다.** 하나는 시도를, 하나는 호출을 가리킨다. 진짜 짝은 `reconcile_count`·`last_reconcile_at` 하나뿐이다 — 백오프가 회차와 시각을 함께 봐야 다음 시점을 정하기 때문이다.
- **호출 기록의 `requested_at`과 어휘가 맞는다.** 그 표의 값들 중 마지막이 거래 테이블의 `last_requested_at`이다. 전에는 이름이 갈려 그 관계를 문장으로 설명해야 했다.
- **결정이 바뀐 것은 없다.** 대사가 집은 횟수와 시도 번호를 가른 것도, 결과를 모르는 동안 같은 키로 부르는 규칙도 그대로다. 바뀐 것은 이름뿐이다.
