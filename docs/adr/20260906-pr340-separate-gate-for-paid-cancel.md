# 결제 전 취소와 결제완료 취소를 다른 관문으로 가른다

- Status: accepted
- Date: 2026-09-06

## Context

지금은 주문 취소 메서드 하나가 상태만 보고 바로 전이한다. 부분취소가 들어오면 **상태는 더 이상 취소 가능 여부의 충분조건이 아니다** — 결제완료이면서 일부만 남은 주문이 정상 상태이기 때문이다.

## Decision

기존 취소 메서드를 **결제 전 전용**으로 좁히고, 결제완료 주문의 품목 취소를 받는 관문을 새로 둔다. 주문을 취소 상태로 만드는 전이는 **공개하지 않고** 그 관문 안에서 모든 잔여가 0인지 스스로 물어 전이한다.

## Consequences

- 성격이 다른 두 전이가 한 가드를 공유하지 않아, 어느 쪽 규칙인지 읽어서 알 수 있다.
- 전이를 공개하지 않으므로 잔여가 남았는데 밖에서 전이시키는 경로가 생기지 않는다.
- 기존 취소 메서드의 호출처가 셋인데(사용자 직접 취소·배치 만료·결제완료 취소) 앞의 둘만 결제 전이다. **셋째를 새 관문으로 옮기는 것과 좁히는 것을 같은 자리에서 해야 한다** — 먼저 좁히면 아직 옮기지 않은 결제완료 경로가 깨진다.
- 총 주문 금액은 취소로 깎지 않는다 — 주문 시점 금액의 사본이고 결제 금액이 거기서 나왔다. 줄이면 결제 금액과의 대조가 조용히 깨진다.
