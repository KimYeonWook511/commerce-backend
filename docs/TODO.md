# TODO

## 상태 분류

- `[todo]`: 시작 전
- `[doing]`: 진행 중
- `[done]`: 완료
- `[blocked]`: 보류 또는 확인 필요

## 작성 규칙

- 각 항목은 하나의 작업 단위로 작성합니다.
- 구현 작업뿐 아니라 테스트 작성, 문서 확인, 예외 케이스 확인도 항목으로 기록합니다.
- 큰 기능 단위보다 바로 실행 가능한 단위로 쪼갭니다.
- 진행 상태는 항목 앞 접두어 태그로 표시합니다.
