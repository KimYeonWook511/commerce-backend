# 태스크 API 스펙

## 개요

이번 태스크는 API 계약을 변경하지 않는다. 14개 application 컴포넌트에 INFO 로그만 추가하므로 요청·응답 구조, 엔드포인트, 검증 규칙은 모두 그대로 유지된다.

## 엔드포인트

- 변경 없음

## 요청

- 변경 없음

## 응답

- 변경 없음

## 검증 규칙

- 변경 없음

## 비고

- 본 작업으로 응답 헤더의 `X-Trace-Id`(P2 #129에서 도입)를 클라이언트가 그대로 활용할 수 있다. 새 INFO 로그가 동일 traceId로 묶이므로 장애 추적 시 클라이언트가 받은 traceId 한 개로 서버 로그를 grep할 수 있다.
