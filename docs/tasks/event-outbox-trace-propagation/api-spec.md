# 태스크 API 스펙

## 개요

본 태스크는 외부 HTTP API의 추가나 변경을 수반하지 않는다. 내부 로깅 인프라(MDC traceId 전파) 보강 작업이다.

기존 API의 응답 헤더 `X-Trace-Id`는 그대로 유지된다.

## 엔드포인트

- 변경 없음

## 요청

- 변경 없음

## 응답

- 변경 없음

## 검증 규칙

- 변경 없음

## 비고

- 본 태스크의 효과는 로그 시스템에서 traceId 검색 시 거래 전체 흐름이 단일 traceId로 묶이는 것으로 확인된다.
- API 컨트랙트는 영향 받지 않는다.
