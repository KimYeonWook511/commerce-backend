# 기능 DB 스키마

## 개요

- 이번 기능은 기존 `tbl_product`, `tbl_stock`를 읽기 전용으로 사용한다.
- 신규 테이블이나 컬럼 변경은 없다.

## 신규 테이블

- 없음

## 변경 테이블

- `tbl_product`
- 상품 기본 정보 조회에 사용한다.

- `tbl_stock`
- 상품 상세 재고 수량 조회에 사용한다.

## 인덱스

- 신규 인덱스 없음
- 목록 조회는 `tbl_product` 전체 조회 후 `created_at DESC` 정렬을 사용한다.
- 상세 조회 재고 조회는 기존 `tbl_stock.product_id` 유니크 인덱스를 사용한다.

## 데이터 무결성

- `tbl_stock.product_id`는 `tbl_product.id`를 참조한다.
- 상품 상세 조회 시 재고 레코드가 없더라도 API는 `stockQuantity=0`으로 응답한다.

## 마이그레이션 고려사항

- 스키마 변경이 없으므로 마이그레이션은 필요 없다.
- 운영 데이터에서 재고 레코드 누락 여부는 별도 운영 점검 대상으로 본다.
