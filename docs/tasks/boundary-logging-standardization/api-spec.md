# 태스크 API 스펙

## 개요

이 태스크는 새로운 API를 추가하거나 기존 API의 계약(요청/응답 형식, 상태 코드)을 변경하지 않는다.

운영 로그만 표준화하므로 클라이언트가 관측 가능한 변화는 없다. `X-Trace-Id` 응답 헤더는 이미 P2(#129)에서 도입되어 본 작업과 무관하게 유지된다.

## 엔드포인트

- 변경 없음.

## 요청

- 변경 없음.

## 응답

- 응답 본문/헤더 변경 없음.
- 단, 동일 요청에 대한 응답 시간이 액세스 로그·예외 핸들러·NaverPay 로그 추가로 1ms 미만 증가할 수 있다 (SLF4J placeholder는 lazy 평가이며 prod root level INFO에서 DEBUG는 침묵).

## 검증 규칙

- 변경 없음.

## 비고

- 본 태스크는 인증/권한 정책을 변경하지 않는다.
- AccessLogFilter는 인증 Filter 이전에 실행되므로 액세스 로그는 인증 실패한 요청도 동일하게 남는다(traceId/method/path/status까지). memberId는 인증 이후 채워지므로 미인증 요청의 액세스 로그에서는 빈 값이다.
