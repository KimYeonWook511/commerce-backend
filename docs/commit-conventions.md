# 커밋 컨벤션

## 형식

```text
<type>: <subject>
```

## 허용 타입

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `refactor`: 동작 변화 없는 리팩터링
- `test`: 테스트 추가 또는 수정
- `docs`: 설명 문서 변경
- `chore`: 설정, 도구, 자동화, 운영성 파일 변경

## subject 규칙

- `subject`는 한국어 현재형으로 작성합니다.
- 마침표(`.`)로 끝내지 않습니다.
- 하나의 커밋은 하나의 논리적 변경만 담습니다.
- 모호한 표현은 사용하지 않습니다.
