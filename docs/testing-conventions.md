# 테스트 컨벤션

## 기본 원칙

- 새로운 기능에는 반드시 테스트를 추가합니다.
- 기존 동작을 수정하면 관련 테스트를 함께 갱신합니다.
- 명시적으로 지시받지 않았다면 테스트를 생략하지 않습니다.

## 테스트 전략

- 테스트 프레임워크는 JUnit 5를 사용합니다.
- 가능하면 단위 테스트를 우선합니다.
- 컨트롤러 테스트는 `@WebMvcTest`를 우선 사용합니다.
- 리포지토리 테스트는 `@DataJpaTest`를 우선 사용합니다.
- 도메인과 서비스 로직은 일반 단위 테스트를 우선 사용합니다.
- `@SpringBootTest`는 정말 필요한 경우에만 사용합니다.

## 네이밍 규칙

- 테스트 메서드명은 `methodName_condition_expectedResult` 형식을 따릅니다.
- 모든 테스트 메서드에는 한국어 `@DisplayName`을 작성합니다.
